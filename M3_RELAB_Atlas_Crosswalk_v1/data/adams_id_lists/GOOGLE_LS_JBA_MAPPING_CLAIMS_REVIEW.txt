Date checked: 2026-10-06

PROVENANCE AND STATUS
---------------------
The proposed group-to-Apollo mapping was supplied by the user from a Google AI
answer.  It is preserved here as a search lead only.  It must not be imported
as ground-truth data.

MAIN FINDING
------------
The answer contains a few correct-looking examples, but its central rule is
wrong: an LS-JBA numeric range does not generally translate to one Apollo
sample.  Exact specimen IDs (including suffix) and, preferably, the associated
CLS measurement ID must be matched to an explicit catalog or literature row.

SUFFIX WARNING
--------------
The Google suffix key is too general to use as metadata.  The meaning of P, M,
N, X, or a number can depend on the specimen series.  In the checked source,
for example, M can describe a magnetic fraction and P can describe a bulk
particulate preparation.  Do not infer grain-size bins or mineral separates
from the letter alone; retain the suffix verbatim and obtain the preparation
description from an explicit record.

RECOMMENDED RULE
----------------
Accept only an exact mapping of the form:

  full Adams specimen ID + CLS file ID -> Apollo/Luna sample ID

when it is supported by a named source.  Keep unverified Google mappings in a
separate leads table; do not propagate a verified mapping from one suffix to an
entire LS-JBA prefix group.
